# Dainichi-ji Temple — React Starter

A responsive React/Vite starter inspired by the calm, editorial feel of the provided landing-page reference and the restrained information architecture of Todaiji's English site.

## Run locally

```bash
npm install
npm run dev
```

Then open the local URL printed by Vite.

## Build

```bash
npm run build
```

## Pages

- `/` — Landing page
- `/visit` — Visitor information
- `/teachings` — Short teachings/reflections
- `/calendar` — Seasonal events
- `/about` — Temple history and architecture
- `/contact` — Contact information

## Notes

- The attached design reference is kept at `public/images/design-reference.jpg` for reference only.
- Photography currently uses sample Unsplash URLs. Replace these with licensed temple photography before launch.
- Temple copy is deliberately conservative/sample-oriented until the exact Dainichi-ji location and official content are confirmed.
- The header, footer, cards, page hero, responsive navigation, and typography are all implemented from scratch in React/CSS.
